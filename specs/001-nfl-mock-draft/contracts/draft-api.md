# Draft API Contract

## Overview

The backend exposes REST endpoints for authentication, team board management, player data, draft workflow, and audit review. All API calls are authenticated unless explicitly noted.

## Authentication

### POST /api/auth/register

Request body:
- email: string
- password: string
- first_name: string
- last_name: string

Response:
- 201 Created
- user_id: string
- token: string

### POST /api/auth/login

Request body:
- email: string
- password: string

Response:
- 200 OK
- token: string
- refresh_token: string

## Draft lifecycle

### POST /api/drafts

Request body:
- controlled_team_id: string
- draft_year: integer

Response:
- 201 Created
- draft_run_id: string
- status: string
- controlled_team_id: string

### GET /api/drafts/{draft_run_id}

Response:
- 200 OK
- draft metadata
- current pick number
- current team on the clock
- status

### POST /api/drafts/{draft_run_id}/picks

Request body:
- player_id: string
- team_id: string

Response:
- 201 Created
- pick record
- updated draft state

### POST /api/drafts/{draft_run_id}/auto-simulate

Triggers engine simulation for non-controlled teams.

Response:
- 200 OK
- next pick context
- auto-selected player

## Team boards

### GET /api/teams/{team_id}/board

Response:
- 200 OK
- default board and user-specific board context

### POST /api/boards/{team_board_id}/entries

Request body:
- player_id: string
- rank_position: integer

Response:
- 201 Created
- board entry

### PUT /api/boards/{team_board_id}

Request body:
- entries: array of player ids in order

Response:
- 200 OK
- updated board version

## Player data

### GET /api/players/{player_id}

Response:
- 200 OK
- player details
- rating signals
- derived UMM_Ranking

### GET /api/players/search

Query parameters:
- q: string
- position: string|null
- college: string|null

Response:
- 200 OK
- list of matching players with current rankings

## AI-assisted recommendation

### POST /api/drafts/{draft_run_id}/recommendation

Request body:
- team_id: string
- current_pick_number: integer
- available_players: array of player ids

Response:
- 200 OK
- recommended_player_id: string
- confidence: number
- rationale: string

## Security and audit endpoints

### GET /api/audit-events

Response:
- 200 OK
- list of the current user's audit events

### GET /api/admin/audit-events

Restricted to authorized administrators only.

## Error patterns

- 400 Bad Request for invalid payloads or invalid ranking inputs.
- 401 Unauthorized for missing or invalid authentication token.
- 403 Forbidden for draft or board access not owned by the user.
- 404 Not Found for missing draft, team, or player.
- 409 Conflict for duplicate player selections or invalid board changes.
- 500 Internal Server Error for unhandled backend exceptions.

## Notes

- The draft engine enforces one controlled team per run.
- Non-controlled team selections must be generated by server-side engine logic, not client-side only.
- All ranking updates must preserve and expose raw signal history and derived UMM_Ranking versions.
